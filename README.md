# SportPlay

Веб-приложение для организатора спортивных мероприятий.

Проект предназначен для упрощения процесса создания и проведения спортивных мероприятий. Организаторы могут управлять мероприятиями, пользователи просматривать доступные события и регистрироваться для участия.

## Возможности

- Регистрация пользователей

- Авторизация через VK ID

- Создание и управление спортивными мероприятиями

- Регистрация участников на мероприятия

- Работа с личным кабинетом пользователя

- Взаимодействие клиентской и серверной частей через REST API
- Реализованы 3 вида оплаты ( система баланса, указание перевода или наличной оплаты услуги)
